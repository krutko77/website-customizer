# CLAUDE.md — инструкции для Клода в этом проекте

## Что это за проект

`website-customizer` — инструмент для внесения правок на сайты (вёрстка,
стили, UI). Не бэкенд-приложение и не Б24-дашборд (тот шаблон удалён,
см. `docs/decisions.md` → D-002). Полное описание — в
[docs/project-brief.md](./docs/project-brief.md), карта проекта — в
[docs/handoff.md](./docs/handoff.md). **Читай их первыми в новой сессии.**

## Стек

Не выбран — `package.json` пока без зависимостей. Стек подбирается под
конкретную задачу правки, а не фиксируется заранее (см. D-002). Если для
задачи нужен сервер — уточни у пользователя, прежде чем добавлять
зависимости или менять `package.json`.

## Инструменты (скиллы)

Полный список и типовой рабочий процесс — в
[docs/architecture.md](./docs/architecture.md). Коротко:
- Правки вёрстки/дизайна — `frontend-design`, `theme-factory`, `ui-ux-pro-max`.
- Проверка в браузере — `playwright-skill`, `webapp-testing`. Работают
  (проверено, см. D-003) — Chromium запускается без root, доустановка
  системных библиотек не нужна.
- Процесс работы — `superpowers`, `skill-creator`.

## Журнал проекта и коммиты

История и текущее состояние проекта живут в `docs/` — см. порядок чтения
в [docs/handoff.md](./docs/handoff.md) (project-brief → state → changelog
→ decisions). Правила:

- После каждого осмысленного шага обновляй `docs/state.md` и дописывай
  `docs/changelog.md`, затем коммить через `bash scripts/snapshot.sh "..."`.
- Неочевидные решения (выбор стека, обход бага, архитектурный выбор)
  фиксируй в `docs/decisions.md` (шаблон записи там же, либо `/decision`).
- В конце сессии — `/end`: обновляет `state.md`, `changelog.md`,
  `last-session.md`, снимок в `handoff.md`, коммитит.
- `scripts/snapshot.sh` сам инициализирует git при первом запуске и
  пушит на GitHub, если настроен remote (сейчас не настроен).

## Деплой

`deploy-vps.sh` — деплой на VPS ЕС Транс (201.51.4.183) через PM2 + nginx
+ certbot. Перед первым запуском для нового сайта замени в скрипте
`APP_NAME`, `APP_PORT` (проверь занятые: `ss -tlnp` на сервере, последний
известный свободный — 3004, сверяй заново), `APP_DOMAIN`. Скрипт сейчас
ссылается на `src/server.js`, которого нет — применим только когда
появится серверная часть.

## Известные ограничения окружения

- Нет `sudo`/root — `apt-get install`, `playwright install-deps` и т.п.
  не выполнить. Обычно не требуется (см. D-003).
- Прямые `fetch` к github.com блокированы — использовать `curl`/`git`.
- `gh` CLI не установлен.
- Запись файлов в `.claude/commands/` — только через python3.
