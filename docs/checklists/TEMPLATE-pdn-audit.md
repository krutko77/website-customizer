# Аудит сайта на соответствие законодательству РФ о персональных данных

> **Шаблон отчёта.** Копируй этот файл под каждый проверяемый сайт:
> `docs/checklists/audit-<домен>-<ГГГГ-ММ-ДД>.md`, заполняй колонки
> «Статус», «Факт» и «Замечание». Методичка с пояснениями, обоснованиями
> и накопленными граблями — [152-fz-website-audit.md](./152-fz-website-audit.md);
> нумерация пунктов здесь ей соответствует.
>
> ⚠️ Инженерный чек-лист для технической проверки, **не юридическое
> заключение**. Пункты 🧑‍⚖️ из кода не выводятся — их подтверждает
> владелец сайта или юрист.
>
> ⚠️ Только право РФ. Норма GDPR, у которой нет аналога в 152-ФЗ, —
> это рекомендация, а не нарушение (например, отдельная кнопка отзыва
> cookie-согласия; см. п. 6.1).

## 4. Cookie, трекеры и аналитика

⚠️ Проверять **каждую страницу**, а не только главную, и **фактическое
поведение сети**, а не разметку. Виджет может грузиться общим ленивым
загрузчиком в обход системы согласия.

Фактическая картина по сценариям:

| Сценарий | Внешние хосты | Cookie | Страниц проверено |
|----------|---------------|--------|-------------------|
| До выбора | | | |
| После «Отказаться» | | | |
| После «Принимаю» | | | |

| № | Пункт проверки | Норма | Метод | Статус | Что фактически | Приоритет | Кто закрывает | Замечание / что делать |
|---|----------------|-------|-------|--------|----------------|-----------|---------------|------------------------|
| 4.1 | Проверены **все** страницы сайта, а не только главная | ч. 1 ст. 9 152-ФЗ | 🔍 Playwright по списку страниц из sitemap | | | | | |
| 4.2 | Cookie-баннер показывается при первом визите, до установки необязательных cookie | ч. 1 ст. 9 152-ФЗ | 🔍 Playwright, изолированный контекст | | | | | |
| 4.3 | Модель **opt-in**: до явного выбора аналитические/рекламные скрипты не загружаются и cookie не ставятся | ч. 1 ст. 9 152-ФЗ | 🔍 Playwright: список запросов и cookie **до** клика | | | | | |
| 4.4 | Блокируется загрузка **самого скрипта** счётчика, а не только вызов `init` (иначе cookie всё равно ставятся) | ч. 1 ст. 9 152-ФЗ | 🔍 сетевой лог: `tag.js` не запрошен до согласия | | | | | |
| 4.5 | «Отказаться» реально отказывает: после отказа трекеры не грузятся, cookie не появляются | ч. 1 ст. 9 152-ФЗ | 🔍 Playwright, сценарий decline | | | | | |
| 4.6 | Отказаться так же просто, как согласиться: обе кнопки на первом экране, равнозначны по видимости (площадь, кегль) | ч. 1 ст. 9 152-ФЗ (свобода воли) | 🔍 Playwright: bounding box + font-size обеих кнопок | | | | | |
| 4.7 | Решение сохраняется, баннер не показывается повторно при reload и переходах | — (UX-следствие ч. 1 ст. 9) | 🔍 Playwright: reload + переход | | | | | |
| 4.8 | На многоязычном сайте баннер и все заглушки согласия — на языке страницы; цепочка определения языка повторена **целиком** (localStorage → navigator.language → дефолт), значение валидируется по списку | ч. 1, ч. 4 ст. 9 152-ФЗ (информированность) | 🔍 Playwright: `newContext({ locale })` с пустым localStorage по всем локалям + одна неподдерживаемая | | | | | |
| 4.9 | Согласие можно отозвать/изменить, после отзыва трекеры не грузятся в новых сессиях, cookie трекера удаляются | п. 8 ч. 4 ст. 9 152-ФЗ | 🔍 сценарий отзыва + перечень cookie после | | | | | |
| 4.10 | Сторонние виджеты инвентаризированы: формы CRM, чаты, карты, видео, соцсети, капча, шрифты — каждый отдельный трекер | п. 1 ч. 1 ст. 14 152-ФЗ | 🔍 полный список внешних хостов, разобрать построчно | | | | | |
| 4.11 | Поведенческая аналитика (вебвизор, запись сессий, карты кликов) описана в документах / вынесена отдельно | ч. 4 ст. 9 152-ФЗ (выводится, прямой статьи нет — помечать ⚠️) | 🔍 наличие `_ym_visorc` и аналогов + текст Политики | | | | | |
| 4.12 | Перечень cookie в документах совпадает с фактическим (имена, владелец, назначение, срок) | ч. 1 ст. 9 152-ФЗ (информированность) | 🔍 сверка списка после accept с политикой cookie | | | | | |
| 4.13 | Технически необходимые cookie отделены, не требуют согласия и не используются для аналитики под видом «необходимых» | ч. 1 ст. 9 152-ФЗ | 🔍 разбор назначения каждой first-party cookie | | | | | |
