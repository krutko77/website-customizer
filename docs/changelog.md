## 2026-08-11 — Cookie-баннер для es-trans.ru
- Разведка сайта (curl + playwright): статический HTML на nginx, уже стоит
  сторонний cookie-баннер `cookieinfoscript.com`, но он не блокирует
  Яндекс.Метрику до согласия — счётчик стартует безусловно в `<head>`.
  Цвета баннера (серый/жёлтый) не совпадают с фирменным стилем сайта
  (красный `#dc2025`/бело-серый)
- Написан `sites/es-trans-ru/cookie-banner/cookie-banner.js` + `.css`:
  баннер согласие/отказ со ссылками на `/privacy-policy.html` и
  `/agreement.html`, решение хранится в `localStorage`, инициализация
  Метрики вынесена в `window.__esTransInitMetrika` и вызывается только
  после реального согласия
- Протестировано headless Playwright (6/6 сценариев): показ при первом
  визите, блокировка Метрики до клика, поведение после «Принимаю» и
  «Отказаться», сохранение решения между перезагрузками
- Инструкция по замене старого скрипта на новый — в
  `sites/es-trans-ru/cookie-banner/README.md` (точные диффы по строкам
  HTML, снимок исходной страницы сохранён рядом)
- Внедрение на прод не выполнялось — нет доступа к деплою/CMS сайта,
  только подготовлены файлы и инструкция
