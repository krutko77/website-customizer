последствия: стек, способ авторизации, структура данных, внешний сервис,
обход известного бага и т.п. Мелочи (имя переменной) сюда не нужны.

## D-002 · Перепрофилирование под правки на сайтах, выбор скиллов
**Дата:** 2026-08-11 · **Статус:** принято · частично отменяет D-001

**Контекст.** Проект назывался `website-customizer`, но содержал шаблон
Б24-дашборда (Express + VibeCode API + Chart.js). Пользователь подтвердил:
дашборды в Битрикс здесь разрабатываться не будут, нужен инструмент для
внесения правок на сайты.

**Варианты.** (A) Оставить код Б24 «на всякий случай». (B) Удалить весь
Б24-код и документацию. (C) Вынести в отдельную ветку/репозиторий.

**Решение.** Вариант B — удалили `src/` целиком и всю Б24-документацию.
Скиллы ставим локально в `.claude/skills/`, не глобально.

**Почему.** Мёртвый код вводит в заблуждение следующего исполнителя и
мешает автодополнению/поиску. История есть в git, восстановить можно.
Локальная установка скиллов — чтобы не засорять другие проекты.

**Критерий отбора скиллов.** Только проверенные и недавно обновлённые:
приоритет официальному `anthropics/skills` (167k★); сторонние — от 3000★
и с обновлением в пределах месяца, плюс ручной аудит кода на предмет
посторонних сетевых вызовов и `exec`. По этому критерию отклонены
`willmarple/playwright-skill` (7★) и `akaihola/playwright-py-skill` (3★).

**Последствия.** `package.json` остался без зависимостей — стек выбирается
под конкретную задачу. `deploy-vps.sh` сохранён (универсальный деплой на
VPS), но применим только если появится серверная часть.

## D-003 · Проверка браузерной автоматизации: блокер снят
**Дата:** 2026-08-11 · **Статус:** принято

**Контекст.** Прошлый снимок фиксировал, что Chromium не запускается —
`npx playwright install-deps chromium` требует root, а `sudo` в окружении
нет.

**Проверка.** Запустили headless Chromium напрямую через `playwright`
внутри `.claude/skills/playwright-skill/` (там уже стоит `npm install`) —
браузер стартовал и загрузил страницу без доустановки системных библиотек.

**Решение.** Считаем блокер снятым: `install-deps` действительно падает
без root, но нужные библиотеки уже есть в образе, и обычный
`npx playwright install chromium` (без `-deps`) плюс `npm install` в
папке скилла достаточны для работы.

**Последствия.** `playwright-skill` и `webapp-testing` пригодны к
использованию. Если в будущем понадобятся firefox/webkit — их запуск
нужно проверять отдельно, гарантии на них эта проверка не даёт.
