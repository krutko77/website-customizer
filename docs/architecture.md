# Архитектура проекта website-customizer

## Назначение

Проект для внесения различных правок на сайты: вёрстка, стили, UI,
проверка результата в браузере.

## Структура файлов

```
website-customizer/
├── docs/                   ← история и состояние проекта
├── scripts/snapshot.sh     ← коммит + пуш на GitHub
├── deploy-vps.sh           ← деплой на VPS (PM2 + nginx + SSL)
├── .env.example
├── CLAUDE.md               ← инструкция для Клода
└── .claude/skills/         ← установленные скиллы
```

---

## Установленные скиллы

| Скилл | Зачем | Источник |
|-------|-------|----------|
| `webapp-testing` | Playwright: проверка фронтенда, скриншоты, логи браузера | anthropics/skills |
| `playwright-skill` | Браузерная автоматизация: автодетект dev-серверов, формы, логины | lackeyjb/playwright-skill |
| `frontend-design` | Визуальное направление при переделке UI | anthropics/skills |
| `theme-factory` | 10 готовых тем (цвета/шрифты) для перекраски страниц | anthropics/skills |
| `skill-creator` | Создание собственных скиллов под повторяющиеся задачи | anthropics/skills |
| `superpowers` | Процесс: TDD, отладка, планы, код-ревью | obra/superpowers |
| `ui-ux-pro-max` | Дизайн-система, стилизация, брендинг | ui-ux-pro-max-skill |

> ⚠️ **Два первых скилла требуют рабочего браузера.** В текущем окружении
> Chromium не запускается — не хватает системных библиотек, а root для их
> установки недоступен. Подробности и варианты решения — в
> [state.md](./state.md) → «Открытые вопросы / блокеры».

## Типовой рабочий процесс

```
1. Получить задачу на правку сайта
       ↓
2. Открыть страницу / посмотреть текущее состояние
   (playwright-skill или webapp-testing)
       ↓
3. Внести правки в вёрстку / стили
   (frontend-design, ui-ux-pro-max, theme-factory)
       ↓
4. Проверить результат в браузере, снять скриншот
   (webapp-testing)
       ↓
5. Записать шаг в журнал и закоммитить (/log)
```

---

## Деплой

`deploy-vps.sh` — универсальный скрипт деплоя на VPS: упаковка,
загрузка по scp, установка зависимостей, запуск через PM2,
настройка nginx и выпуск SSL через certbot.

Перед первым запуском заменить: `APP_NAME`, `APP_PORT`, `APP_DOMAIN`.
