## Где мы сейчас

Cookie-баннер для `es-trans.ru` частично выложен на прод клиентом, но
**не работает** — диагностировано в этой сессии. Причина: на сервере
применён только Шаг 2 инструкции (обёртка Яндекс.Метрики в
`window.__esTransInitMetrika` — это в HTML есть и корректно). Шаг 1
(загрузка файлов `js/cookie-banner.js`, `css/cookie-banner.css` на
сервер) и Шаг 3 (подключение `<link>`/`<script>` этих файлов в HTML)
**не выполнены**: оба файла отдают 404, тега
`<script src="js/cookie-banner.js">` в HTML нет вообще — поэтому баннер
не появляется и ошибок в консоли тоже нет (браузер даже не запрашивает
несуществующий скрипт). Старый сторонний баннер `cookieinfoscript.com`
уже удалён — то есть сейчас на сайте вообще нет cookie-баннера, а
Метрика при этом корректно не инициализируется (ждёт вызова функции,
которую некому вызвать).

Актуальный HTML сайта на момент проверки: `app.min.js?_v=20260811171125`,
last-modified 2026-08-11 14:12 UTC — то есть клиент правки заливал
сегодня, но не полностью.

GitHub PAT ротирован (прошлая сессия): старый (`ghp_...ye1EkTdP`)
заменён новым, пуш работает штатно, upstream-трекинг `main` →
`origin/main` в порядке.

## Сейчас в работе

Диагностика причины, почему баннер не появляется на проде — завершена,
причина найдена и объяснена пользователю. Патч (точные строки под
актуальный HTML) ещё не подготовлен — пользователь не успел подтвердить,
