**Диагноз.** В `data-map-src` на проде стоит ссылка **для перехода** на
сайт Яндекс.Карт, а не URL встраиваемого виджета:

```
https://yandex.ru/maps/?um=constructor:dad8984b…&source=constructorLink
                    ↑ /maps/                      ↑ constructorLink
```

Такой URL Яндекс отдаёт с `X-Frame-Options: DENY` — браузер обязан
отказать в отрисовке iframe. Проверено `curl`-ом, а не по памяти:

| URL | `X-Frame-Options` | Во фрейме |
|---|---|---|
| `/maps/?…&source=constructorLink` (на проде) | `DENY` | ❌ блокируется |
| `/map-widget/v1/?…&source=constructor` | заголовка нет | ✅ грузится |

Надпись про `yandex.by` — то же самое: `/maps/` дополнительно редиректит
на региональный домен, и уже он блокируется. **Важно для следующего:**
заглушка на скриншоте **браузерная, а не наша** — то есть гейтинг по
согласию отработал штатно, `loadMap()` вызвался, iframe создан. Ломается
исключительно URL, логика cookie-баннера ни при чём и трогать её не надо.

**Готовая правка** (в `contacts.html` меняется только значение атрибута,
два отличия — путь и `source`):

```html
<div class="contact__map"
    data-map-src="https://yandex.ru/map-widget/v1/?um=constructor%3Adad8984b336259f49920289107cb16f22c256c86243b42100f2d8bb2050ae10d&amp;source=constructor">
</div>
```

Остальная разметка корректна: `data-map-src` (не `data-src`) и без
вложенного `<iframe>` — требование из комментария в файле соблюдено,
обхода согласия нет.

**Побочная находка — репозиторий разошёлся с продом по ID карты.**
На проде `constructor:dad8984b…`, в
`sites/es-trans-ru/consent-gating-fix/contacts.AFTER.html` —
`constructor:9d231bda…`. Прод-ID **валиден**: виджет по нему отдаёт
правильную метку («ЕС Транс», «Московская область, Химки, Коммунальный
проезд, 2») — проверено запросом. Значит карту пересобирали в
конструкторе после нашей правки 18.08, и сохранять надо **прод-овский**
ID, а не откатывать на репозиторный. ⚠️ Если этого не сделать, при
следующей выкладке из репозитория карта откатится на старую.

**Гипотеза о причине** (не проверена, но объясняет всё): при пересборке
карты в конструкторе Яндекса скопировали ссылку из вкладки «Ссылка на
карту» вместо «Код для вставки» — они выглядят почти одинаково, но
первая для фрейма непригодна.

**Два вопроса пользователю остались без ответа** (сессия завершена
