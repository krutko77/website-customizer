## Где мы сейчас

Проект перепрофилирован под внесение правок на сайты. Прежнее наполнение
(шаблон Б24-дашборда: Express + VibeCode API + Chart.js) удалено —
дашборды в Битрикс в этом проекте разрабатываться не будут.

Установлено 5 новых скиллов под работу с сайтами: `webapp-testing`,
`frontend-design`, `theme-factory`, `skill-creator` (все из официального
`anthropics/skills`) и `playwright-skill` (lackeyjb, 3013★). Вместе с
ранее стоявшими `superpowers` и `ui-ux-pro-max` — 35 скиллов всего.

Правка вёрстки, дизайн и темы, а также браузерная автоматизация
(`playwright-skill`, `webapp-testing`) — готовы к работе, проверены
реальным запуском (D-003). `CLAUDE.md` заполнен инструкциями для Клода
(стек, скиллы, процесс, деплой, ограничения окружения) — раньше был
пустым.

Проект под git, подключён к GitHub: `origin` →
`https://github.com/krutko77/website-customizer.git`, ветка `main`
запушена (`bced988`).

## Открытые вопросы / блокеры

- `package.json` сейчас пустая заготовка без зависимостей. Стек зависит от
  того, какого рода правки будут вноситься — уточнить.
- `[branch "main"]` в `.git/config` без строки `remote = origin` (upstream
  трекинг настроен частично) — `git push`/`git pull` без аргументов может
  потребовать `-u`/явного указания remote+ветки при следующем разе.
