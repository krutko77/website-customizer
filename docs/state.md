Проект перепрофилирован под внесение правок на сайты. Прежнее наполнение
(шаблон Б24-дашборда: Express + VibeCode API + Chart.js) удалено —

## Открытые вопросы / блокеры

- **Браузер не запускается в этом окружении.** Пакет `playwright` и сам
  Chromium скачаны (`npm install` + `npx playwright install chromium`
  выполнены успешно), но бинарник не стартует: не хватает 20 системных
  библиотек (`libglib-2.0.so.0`, `libnss3.so`, `libX11.so.6`, `libasound.so.2`
  и др.). Ставятся они через `apt-get install` — нужен root, а `sudo` в
  окружении нет.
  Варианты: (а) попросить админа выполнить
  `npx playwright install-deps chromium` от root; (б) работать с браузером
  на другой машине/в контейнере с нужными библиотеками.
  До этого `playwright-skill` и `webapp-testing` работать не будут —
  остальные скиллы (правка вёрстки, дизайн, темы) от этого не зависят.
- `package.json` сейчас пустая заготовка без зависимостей. Стек зависит от
  того, какого рода правки будут вноситься — уточнить.
