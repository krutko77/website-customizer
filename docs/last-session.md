- Заменить сторонний cookie-баннер на собственный, а не просто
  перекрасить существующий — потому что сторонний скрипт не решал
  главную проблему (не блокировал Метрику до согласия), а просто менять
  цвета в data-атрибутах не устранило бы это
- Баннер ссылается на обе страницы политик сайта (`privacy-policy.html`
  и `agreement.html`), а не только на одну — по прямому запросу
  пользователя

## Подводные камни
- **`.env.example` — не гитигнорится, в отличие от `.env`.** Секреты туда
  класть нельзя, уйдут в публичный репозиторий при следующем коммите
- Новый GitHub PAT (`ghp_...uV2H91Vj`) нигде не сохранён — ни в файлах
  проекта, ни в git-конфиге. Для следующего пуша (если credential helper
  так и не настроен) понадобится либо этот же токен от пользователя,
  либо новый
- `deploy-vps.sh` запускает через PM2 `src/server.js`, которого нет —
  перед деплоем указать реальную точку входа
- Прямые `fetch`-запросы к github.com заблокированы; GitHub доступен
  через `curl`/`git`. Обычные внешние сайты (например, es-trans.ru) через
  `curl` доступны без ограничений
- Push через HTTPS требует credentials на каждый раз — ни `gh` CLI, ни
  SSH-ключ, ни credential helper в окружении не настроены
- Запись в `.claude/commands/` требует python3, а не bash `cat` или Write
