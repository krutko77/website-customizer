## Ключевые решения

- **Не писать новый код, а свериться с существующим патчем.** Инструкция
  по памяти или «по здравому смыслу» разошлась бы с файлами, которые
  владелец будет выкладывать, — расхождение вскрылось бы уже на хостинге.

  со стабом PHPMailer, фолбэк при недоступной БД проверен, но на **живой
  MySQL патч не прогонялся** — в этой среде нет драйверов PDO. Сказано
  пользователю прямо, а не подано как «полностью проверено».

  письмо ушло, а запись не создалась, останутся ПДн без доказательства
  согласия; лишняя запись без письма безопаснее.
