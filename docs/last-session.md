## Подводные камни

- **Исходники сайта недоступны** — Gulp-проект на ноутбуке клиента.
  Все правки готовятся текстовым патчем и выкладываются владельцем.
  `sendmail.php` мы тоже видим только в присланной копии, поэтому
  серверная проверка велась **снаружи**, по различимости ответов. Если
  владелец пришлёт актуальный файл — вывод можно уточнить точнее.
- **Попапы с формами и футер продублированы на каждой странице**, общего
  include нет: правка без полной пересборки расходится не на весь сайт.
  Проверять все страницы, а не одну.
- **Playwright не кликнет по форме в скрытом попапе** («outside of the
  viewport») — нужно через `page.evaluate` форсировать
  `display/visibility/opacity` у родителей, иначе ложные ❌.
- **Проверяя заглушки, помни, что они заменяются содержимым** — именно
  на этом тест дал ложный ❌ по адресу на карте. Снимать состояние
  заглушки **до** действия пользователя.
- **Сервер отвечает 200/0 байт на всё**, включая GET и пустой POST —
  диагностики нет, отличать поведение приходится по совокупности
  признаков, а не по телу ответа.
- **`grep` по `app.min.js` отваливается по таймауту** (358 КБ одной
  строкой) — тянуть куски точечно через python3.
