# Логотип ES·TRANS.RU — белая версия (для печати на куртках)

Взят оригинальный вектор с сайта (`https://es-trans.ru/img/logo.svg`,
CorelDRAW, два цвета). Тёмный `#4A4A48` заменён на белый `#FFFFFF`,
красный `#DC2025` не тронут. Сайт при этом **не менялся** — файл только
скачан и перекрашен.

| Файл | Что это |
|---|---|
| `es-trans-logo-white.svg` | белая версия, вектор, ширина 600 px, **фон прозрачный** |
| `es-trans-logo-white.png` | та же, 600×93 px, **фон прозрачный** (RGBA) |
| `es-trans-logo-white.jpg` | та же, 600×93 px, фон `#353535` (цвет куртки с образца) |
| `es-trans-logo-original.svg` | копия оригинала с сайта, без изменений (на случай пересборки) |

JPEG не умеет прозрачность, а белый на белом не виден — поэтому у JPEG
тёмный фон. Для печати лучше SVG: масштабируется без потери качества.
В SVG перекраска — одна строка в `<style>` (`.fil1`), размер задан через
`width`/`height` при сохранённом `viewBox`.
