# Логотип ES·TRANS.RU — белая версия (для тёмного фона)

Тёмно-серый цвет оригинала заменён на белый `#ffffff`, красный `#dc2025`
не тронут. Сделано по образцу с куртки (скриншот пользователя 2026-11-20).

| Файл | Что это |
|---|---|
| `es-trans-logo-white.svg` | вектор, ширина 600 px, **фон прозрачный** |
| `es-trans-logo-white.jpg` | 600×93 px, фон `#353535` (цвет куртки с образца) |

JPEG не умеет прозрачность, а белый текст на белом фоне не виден — поэтому
у JPEG тёмный фон. Если нужен другой цвет фона — поменять `#353535` в
`jpg.cjs` и пересобрать.

## Как получено (важно)

Векторного исходника логотипа у нас нет — только растр 362×104 px
(`source-logo-362px.png`). SVG — **трассировка** этого растра (potrace,
два слоя: красный и тёмный), а не оригинальные кривые. Углы букв чуть
мягче оригинала. Если у владельца есть исходный векторный файл
(ai/eps/svg) — лучше перекрасить его: результат будет точнее.

Пересборка: `npm i potrace jimp` в пустой папке → `node trace.cjs` →
`node build.cjs` → `node jpg.cjs` (скрипты рассчитаны на рабочую папку
`/tmp/logo-work`, пути внутри править под себя).
