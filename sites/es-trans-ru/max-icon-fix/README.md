# Фикс: иконка MAX полностью чёрная в Firefox

## Причина

Иконка MAX в шапке сайта подключена как SVG-спрайт:

```html
<svg class="social__icon">
    <use xlink:href="img/icons/icons.svg#max"></use>
</svg>
```

Внутри `img/icons/icons.svg` символ `#max` — это не обычный
одноцветный vector-path (как остальные иконки в этом спрайте), а
градиентная PNG-картинка (закодирована в base64), обрезанная по форме
через `<clipPath>` + `<use xlink:href="#SVGID_1_">`, поверх которой
рисуется белый path со значком чата.

Chrome умеет резолвить внутренние ссылки (`clipPath url(#...)`,
`<use xlink:href="#SVGID_1_">`) даже когда сам символ подключён через
внешний `<use xlink:href="icons.svg#max">`. **Firefox — нет**: при
использовании символа через внешний спрайт внутренние id-ссылки внутри
него не резолвятся, `clipPath` считается пустым, картинка не рисуется
— видна только чёрная заливка того, что осталось.

Проверено: остальные иконки в этом спрайте (Telegram и т.д.) — простые
одноцветные path без вложенных `<svg>`/`clipPath`, поэтому у них эта
проблема не проявляется, баг специфичен именно для `#max`.

## Фикс

Не чинить SVG-спрайт (переусложнённая структура, вложенный `<svg>`
внутри `<symbol>` с обрезкой растровой картинки — так делать не стоило
изначально), а заменить иконку MAX на обычный `<img>` с готовым PNG.
Так одинаково работает во всех браузерах, никаких SVG-трюков.

Файл `max-icon.png` в этой папке — готовая иконка 120×120px (для
чёткости на retina-экранах при отображении 40×40 CSS-пикселей, как
сейчас на сайте). Получена рендером того же самого символа `#max` из
`icons.svg` в Chromium (там clipPath резолвится правильно) и
экспортом в PNG — визуально идентична тому, что сейчас видно в Chrome.

### Шаг 1 — загрузить файл на сервер

Положить `max-icon.png` в `img/icons/max-icon.png` (рядом с
`icons.svg`).

### Шаг 2 — заменить разметку иконки

Найти в шаблоне шапки (партиал, используется на каждой странице —
судя по всему тот же файл, где менялись cookie-banner/bitrix24-form):

```html
<a class="social__link" target="_blank" href="https://max.ru/u/...">
    <svg class="social__icon">
        <use xlink:href="img/icons/icons.svg#max"></use>
    </svg>
</a>
```

Заменить на:

```html
<a class="social__link" target="_blank" href="https://max.ru/u/...">
    <img class="social__icon" src="img/icons/max-icon.png" alt="MAX" width="40" height="40">
</a>
```

CSS менять не нужно — класс `social__icon` уже задаёт `height:40px;
width:40px` и transition для hover, эти правила одинаково применяются
и к `<svg>`, и к `<img>`.

### Шаг 3 — проверить

1. Открыть сайт в Firefox — иконка MAX должна показывать градиентный
   квадрат сине-фиолетового цвета с белым значком чата (как в Chrome),
   а не чёрное пятно.
2. Проверить в Chrome — иконка должна выглядеть точно так же, как до
   фикса (визуальных изменений быть не должно, картинка идентична).
3. Проверить hover — при наведении иконка должна слегка тускнеть
   (`opacity: .7`), как раньше.

## Что НЕ трогать

Символ `#max` в `img/icons/icons.svg` можно оставить как есть — им
больше никто не пользуется после замены разметки, удалять
необязательно (не мешает).
